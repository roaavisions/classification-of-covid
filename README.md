# Classification of COVID-19 in Chest X-Ray Images Using Deep Transfer Learning

## 📌 Project Overview

This project applies Deep Learning and Transfer Learning techniques to classify COVID-19 using chest X-ray images.

The project covers data preprocessing, model training, image classification, and performance evaluation using Python and Deep Learning tools.

### 🛠️ Technologies

- Python
- TensorFlow / Keras
- Deep Learning
- Transfer Learning
- Image Processing
## 🎯 Objective

The objective of this project is to develop a deep learning model that can classify chest X-ray images for COVID-19 detection using Transfer Learning
## 📂 Dataset

The dataset consists of chest X-ray images categorized into different classes for COVID-19 classification.

The images were preprocessed and prepared for training, validation, and testing.
This project uses a combination of two publicly available chest X-ray datasets:

1. COVID-19 Chest X-ray Dataset

A collection of chest X-ray images of COVID-19 and other respiratory diseases, including MERS, SARS, and ARDS.

Source:
https://github.com/ieee8023/covid-chestxray-dataset

2. ChestX-ray8 Dataset

A large-scale chest X-ray dataset containing images associated with eight common thoracic diseases.

Source:
https://nihcc.app.box.com/v/ChestXray-NIHCC
## 🔬 Methodology

The project follows these main steps:

1. Data preprocessing
2. Transfer Learning
3. Model training
4. Model evaluation
5. Performance analysis
